📐 Architecture Summary

  • Platform: Android (Kotlin Native + React Native)
  • Detection: AccessibilityService (filter: Instagram / YouTube)
  • Debouncing: 1200ms Dwell Time + UI node signature comparison
  • Floating Pill: TYPE_APPLICATION_OVERLAY (Non-focusable)
  • Storage: AsyncStorage (Zero cloud dependency)
  • Cost: $0 / Local-only / Offline-first
